# Bayesian Crowd Counting model

## Objectiu
Aquesta xarxa neuronal convolucional (CNN) està dissenyada per predir la quantitat de persones presents en una imatge. En concret, està especialitzada en compteig de persones a platges.

## Dades

Per entrenar el model final s'han fet servir imatges de diferents platges de les Illes Balears extretes de diferents webcams públiques.

## Rendiment
El millor model generat ha obtingut un RMSE = 9,39 i un MAE = 6,38. Una millora considerable respecte al model anterior.
| | Model antic | Model nou |
|--|--|--|
|RMSE| [VAL] | 9,39 |
|MAE| [VAL] | 6,38 |
